# Sprint 8 — Admin quản lý bài học tình huống

1. Thêm quyền admin, lệnh cấp quyền và migration giữ nguyên bài đã có.
2. Xây API soạn, xuất bản, ẩn, khôi phục và nhân bản bài, kèm nhật ký thao tác.
3. Giới hạn thư viện học viên theo trạng thái và bảo toàn roleplay đã bắt đầu.
4. Xây danh sách, trình soạn thảo và màn xem trước riêng tại `/admin`.
5. Xuất OpenAPI, sinh kiểu Angular và kiểm tra các luồng chính.
6. Lưu quyết định, hướng dẫn vận hành, báo cáo và bài học kỹ thuật trong repo.
